# Concert Ticket Counter (Dua Lipa - Estadio Nacional)

A Python script that simulates the sale of 1.000.000 concert tickets across the official seating sections of Chile's Estadio Nacional. The program organizes the data alphabetically, counts the total occupied tickets per section using parallel lists, and determines the most popular section.

## How to Run

1. Make sure you have Python 3 installed.
2. Run the script from your terminal:
   ```bash
   python concert_tickets.py
